Entry for the make.fun bounty
[u-rama-melon-make-the-ai-judge-laugh-302d0825](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825)
($2, 10 places).

`main.py` (Python 3.13, stdlib only, no network) writes one one-line joke
about office life to `/output/entry.txt`:

> HR said to bring my whole self to work, so I brought my resignation letter too — it was the only part of me they ever read.

The joke is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
